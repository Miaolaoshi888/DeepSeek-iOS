# 📱 DeepSeek Harness - iPhone 16 Pro Max 使用教程

## ✅ 快速开始（30秒搞定）

### 第一步：确认网络
确保您的 iPhone 16 Pro Max 和运行 DeepSeek Harness 的电脑连接在 **同一个 WiFi 网络**。

### 第二步：获取访问地址
从终端输出可以看到：
- **电脑 IP**: `192.168.1.91`
- **DSH 端口**: `3080`
- **完整地址**: `http://192.168.1.91:3080`

### 第三步：在 iPhone 上访问
1. 打开 **Safari** 浏览器
2. 输入地址：`http://192.168.1.91:3080`
3. 按回车，即可看到 DeepSeek Harness Web GUI

## 🎯 优化体验：添加到主屏幕

让 DSH 像原生应用一样运行：

1. 在 Safari 中打开 `http://192.168.1.91:3080`
2. 点击底部中间的 **分享按钮** ⬆️
3. 向下滑动，选择 **"添加到主屏幕"**
4. 输入名称（如 "DSH" 或 "DeepSeek"）
5. 点击右上角 **"添加"**

现在您的主屏幕上会有 DSH 图标，点击即可全屏使用！

## 🔧 故障排除

### 问题：无法连接

**检查清单：**
- [ ] iPhone 和电脑是否在同一 WiFi？
- [ ] 电脑防火墙是否阻止了 3080 端口？
- [ ] 在电脑浏览器访问 `http://192.168.1.91:3080` 是否正常？

### 解决防火墙问题（Windows）

**临时方案（测试用）：**
1. 暂时关闭 Windows Defender 防火墙
2. 测试连接成功后，再开启防火墙并添加入站规则

**永久方案：**
1. 按 `Win + R`，输入 `wf.msc`，回车
2. 点击左侧 **"入站规则"** → 右侧 **"新建规则"**
3. 选择 **"端口"** → 下一步
4. 选择 **"TCP"**，输入特定本地端口：`3080`
5. 选择 **"允许连接"** → 下一步
6. 全选三个配置文件 → 下一步
7. 命名：`DeepSeek Harness 3080` → 完成

## 💡 高级技巧

### 固定 IP 地址（推荐）

避免每次重启后 IP 变化：

**在路由器中设置：**
1. 登录路由器管理界面（通常 192.168.1.1）
2. 找到 DHCP 设置 → 静态地址分配
3. 为电脑的 MAC 地址分配固定 IP：`192.168.1.91`

**或在 Windows 中设置：**
1. 设置 → 网络和 Internet → Wi-Fi
2. 点击当前网络 → 编辑 IP 分配
3. 选择"手动" → 启用 IPv4
4. 输入：IP `192.168.1.91`，子网 `255.255.255.0`，网关 `192.168.1.1`

### 创建快捷方式

将以下 URL 保存到 iPhone 书签：
```
http://192.168.1.91:3080
```

或者使用 Shortcuts 应用创建自动化脚本。

## 📝 常见问题 FAQ

**Q: 可以在 Chrome 中使用吗？**
A: 可以，但 Safari 体验最佳（更好的 PWA 支持）。

**Q: 需要安装 App 吗？**
A: 不需要，纯 Web 应用，Safari 即可。

**Q: 可以离线使用吗？**
A: 部分功能可以，但需要网络连接与电脑通信。

**Q: 延迟高怎么办？**
A: 检查网络质量，尝试靠近路由器，或有线连接电脑。

**Q: 支持哪些功能？**
A: 所有桌面版功能：代码执行、文件操作、Web 搜索、子代理等。

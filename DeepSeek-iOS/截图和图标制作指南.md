# 📸 DeepSeek iOS - 截图和图标制作指南

## 一、应用图标制作

### 图标规格要求
```
尺寸：1024 x 1024 像素
格式：PNG（带透明通道）
颜色模式：sRGB
文件大小：不超过 10MB
```

### 设计方案建议

#### 方案 A：简洁 Logo 风格
```
背景：渐变蓝色（#667eea → #764ba2）
图标：大脑轮廓 + AI 符号
文字：无（Apple 会自动添加圆角）
```

#### 方案 B：抽象几何风格
```
背景：白色或浅色
图标：三个连接的圆点代表 AI 网络
特点：现代感强，识别度高
```

#### 在线工具（推荐）
```
1. https://appicon.co/

2. https://makeappicon.com/
   - 在线设计图标
```

### 图标设计示例代码

如果您使用代码生成图标：

```swift
import SwiftUI

struct AppIconView: View {
    var body: some View {
        ZStack {
            // 渐变背景
            LinearGradient(
                gradient: Gradient(colors: [
                    Color(red: 0.4, green: 0.49, blue: 0.93),
                    Color(red: 0.46, green: 0.29, blue: 0.64)
                ]),
                startPoint: .topLeading,
                endPoint: .bottomTrailing
            )
            
            // AI 图标
            Image(systemName: "brain.head.profile")
                .font(.system(size: 120, weight: .bold))
                .foregroundColor(.white)
        }
        .cornerRadius(24)
    }
}
```

### 截图制作步骤

#### 方法一：使用 Xcode 模拟器

```
1. 打开 Xcode 项目
2. 运行应用到模拟器（iPhone 16 Pro Max）
3. 调整到需要的界面
4. 快捷键 Cmd + S 截图
5. 选择截图尺寸
6. 保存到桌面
```

#### 方法二：使用模拟器录制

```bash
# 使用 xcrun simctl 录制
xcrun simctl io booted recordVideo screenshot.mp4

# 截图
xcrun simctl shutdown booted
xcrun simctl screenshot booted screenshot.png
```

#### 方法三：使用第三方工具

```
推荐工具：
1. ScreenFlow（Mac）- 专业录屏
2. SnapIt（Mac）- 截图工具
3. ApowerMirror（Win/Mac）- 手机投屏截图
4. GoodSprite（在线）- AI 生成截图
```

### 截图设计要点

#### 1. 登录界面截图
```
内容：
- 品牌 Logo（大且清晰）
- 应用名称
- API Key 输入框（填写示例值）
- 登录按钮
- 干净的背景

技巧：
- 使用深色背景突出白色输入框
- 添加一些装饰元素（如光晕效果）
```

#### 2. 对话界面截图
```
内容：
- 顶部导航栏（显示应用名）
- 多条对话消息（展示对话体验）
- 底部输入栏
- 清晰的 AI 回复

技巧：
- 使用真实的对话内容
- 展示代码高亮效果
- 包含多个消息类型
```

#### 3. 代码执行截图
```
内容：
- 代码编辑器（显示代码）
- 执行按钮
- 输出结果区域
- 语言选择器

技巧：
- 展示真实的代码示例
- 输出结果要清晰可读
- 添加执行成功的反馈
```

### 截图美化技巧

#### 添加阴影效果
```bash
# 使用 ImageMagick 添加阴影
convert screenshot.png -bordercolor white -border 20 \
  -shadow 80x4+4+4 \
  -flatten \
  final_screenshot.png
```

#### 添加设备框架
```bash
# 使用预制的设备框架模板
# 下载 iPhone 16 Pro Max 框架 PNG
# 将截图放到框架中间
```

#### 批量处理
```bash
# 批量调整尺寸
mogrify -resize 1290x2796\! *.png

# 批量添加圆角
convert input.png -bordercolor transparent -border 10 \
  \( +clone -background black -shadow 80x4+4+4 \) \
  +swap -background none -compose Plus -composite \
  output.png
```

## 五、最终检查清单

### 截图检查
```
□ 尺寸正确（1290x2796, 1170x2532 等）
□ 格式正确（PNG/JPEG）
□ 文件大小合适（< 6MB）
□ 内容清晰可读
□ 无外部 UI 元素
□ 展示核心功能
□ 颜色一致美观
```

### 图标检查
```
□ 尺寸 1024x1024
□ PNG 格式（透明背景）
□ 无圆角（Apple 自动处理）
□ 颜色和品牌一致
□ 简洁易识别
□ 高分辨率
```

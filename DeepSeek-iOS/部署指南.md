# DeepSeek iOS 应用 - 部署指南

> 如何在 iPhone 16 Pro Max 上运行 DeepSeek iOS 原生应用

---

## 📋 前置准备

### 硬件要求
- iPhone 16 Pro Max（或任何 iPhone）
- 电脑（Mac 推荐，Windows 需要替代方案）

### 软件要求
- **Mac 用户**：
  - Xcode 15.0+（App Store 免费下载）
  - iOS 16.0+ 设备
  
- **Windows 用户**：
  - 使用 GitHub Actions 云构建
  - 或配置 CI/CD 流水线

---

## 🍎 Mac 用户 - 完整开发环境

### 第一步：安装 Xcode

1. 打开 App Store
2. 搜索 "Xcode"
3. 点击获取并安装（约 10GB）
4. 安装完成后打开 Xcode，同意许可协议

### 第二步：打开项目

```bash
# 在终端中进入项目目录
cd "/Users/yourname/Desktop/DeepSeek-iOS"

# 或者直接用 Finder 打开 .xcodeproj 文件
open DeepSeek-iOS.xcodeproj
```

**注意**：我创建的是 Swift Package 格式。如果需要 Xcode 项目格式，请告诉我，我可以转换。

### 第三步：配置 API Key

**方式一：环境变量（推荐）**
```bash
# 在终端中设置
export AGNES_API_KEY="sk-xxxxx"

# 然后运行 Xcode
open DeepSeek-iOS.xcodeproj
```

**方式二：修改代码**
```swift
// 编辑 Services/APIService.swift
private var apiKey = "你的API Key"
```

### 第四步：运行应用

1. 连接 iPhone 到 Mac
2. 信任开发者模式：
   - iPhone 设置 → 隐私与安全性 → 开发者模式 → 开启
3. 在 Xcode 中选择你的设备
4. 点击运行按钮（▶️）

## 💻 Windows 用户 - 云构建方案

由于 iOS 应用需要在 macOS 上编译，我们提供以下方案：

### 方案 A：GitHub Actions 云构建

创建一个 GitHub Actions workflow：

```yaml
# .github/workflows/build-ios.yml
name: Build iOS App

on:
  push:
    branches: [ main ]

jobs:
  build:
    runs-on: macos-latest
    
    steps:
    - uses: actions/checkout@v3
    
    - name: Setup Xcode
      uses: maxim-lobanov/setup-xcode@v1
      with:
        xcode-version: '15.0'
    
    - name: Build and Archive
      run: |
        xcodebuild archive \
          -scheme DeepSeek \
          -destination 'generic/platform=iOS' \
          -archivePath Build/DeepSeek.xcarchive \
          CODE_SIGNING_ALLOWED=NO
    
    - name: Export IPA
      run: |
        xcodebuild -exportArchive \
          -archivePath Build/DeepSeek.xcarchive \
          -exportPath Build/Exported \
          -exportOptionsPlist ExportOptions.plist
```

### 方案 B：使用第三方服务

- **Codemagic** (https://codemagic.io)
- **Bitrise** (https://www.bitrise.io)
- **Fastlane CI**

## 🔧 转换为 Xcode 项目（推荐）

Swift Package 需要转换为 Xcode 项目才能更方便地开发。请运行：

```bash
# 在项目根目录执行
swift package generate-xcodeproj
```

这会在项目目录生成 `DeepSeek-iOS.xcodeproj` 文件。

## 🐛 常见问题

### Q: Xcode 提示无法找到 Swift Package？
A: 使用 `swift package generate-xcodeproj` 生成项目文件

### Q: 编译失败，显示找不到模块？
A: 确保 iOS 部署目标设置为 16.0+

### Q: API 连接失败？
A: 检查：
- API Key 是否正确
- 网络是否通畅
- Base URL 是否正确：`https://api.agnes-ai.cn/v1`

### Q: 模拟器运行正常，真机报错？
A: 检查：
- 开发者模式已开启
- 设备已信任
- 网络权限已授权

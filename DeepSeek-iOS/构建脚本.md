# DeepSeek iOS 项目构建脚本

## 快速构建

### 方法一：使用 xcodebuild（推荐）

```bash
# 清理
xcodebuild clean -scheme DeepSeek

# 构建
xcodebuild build \
  -scheme DeepSeek \
  -destination 'platform=iOS Simulator,name=iPhone 16 Pro Max' \
  -configuration Debug

# Archive 用于分发
xcodebuild archive \
  -scheme DeepSeek \
  -destination 'generic/platform=iOS' \
  -archivePath Build/DeepSeek.xcarchive
```

### 方法二：使用 Swift Package Manager

```bash
# 生成 Xcode 项目
swift package generate-xcodeproj

# 然后用 Xcode 打开项目
open DeepSeek-iOS.xcodeproj
```

### 方法三：使用 Fastlane（自动化）

```bash
# 安装 fastlane
brew install fastlane

# 初始化
fastlane init

# 构建
fastlane build
```

## 环境变量配置

在运行应用前，确保设置 API Key：

```bash
# macOS/Linux
export AGNES_API_KEY="sk-xxxxx"

# Windows PowerShell
$env:AGNES_API_KEY="sk-xxxxx"
```

或者在 Xcode 中配置：
1. 选择 Scheme → Edit Scheme
2. Run → Arguments → Environment Variables
3. 添加 AGNES_API_KEY

## 测试

```bash
# 运行单元测试
xcodebuild test \
  -scheme DeepSeek \
  -destination 'platform=iOS Simulator,name=iPhone 16 Pro Max'

# 或
swift test
```

## 发布

### TestFlight 测试
```bash
xcodebuild archive \
  -scheme DeepSeek \
  -destination 'generic/platform=iOS' \
  -archivePath Build/DeepSeek.xcarchive \
  CODE_SIGN_IDENTITY="iPhone Developer" \
  PROVISIONING_PROFILE="your-profile UUID"

xcodebuild -exportArchive \
  -archivePath Build/DeepSeek.xcarchive \
  -exportPath Build/Exported \
  -exportOptionsPlist ExportOptions.plist
```

### App Store 发布
1. 上传到 App Store Connect
2. 提交审核
3. 等待审核通过

## 注意事项

- iOS 部署目标：16.0+
- 需要 Apple Developer 账号（$99/年）进行签名和发布
- 测试阶段可以使用免费账号（限制最多 3 台设备）

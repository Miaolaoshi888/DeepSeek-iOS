```bash

2. File → Open → 选择 DeepSeek-iOS.xcodeproj
3. 连接 iPhone（信任此电脑）

```


## 🥉 方案三：Xcode 直接调试（最稳定）

### 前提条件
- ✅ 有一台 Mac
- ✅ 已安装 Xcode 15.0+
- ✅ 有免费的 Apple ID（不需要付费账号）

### 详细步骤

#### 1. 打开项目
```bash
# 在 Mac 上
open "H:\桌面存储\deepseek harness\苹果手机端开发\DeepSeek-iOS.xcodeproj"
```

#### 2. 配置签名
```
1. 点击项目根目录
2. 选择 Target "DeepSeek-iOS"
3. 进入"Signing & Capabilities"
4. 勾选"Automatically manage signing"
5. 选择您的个人 Apple ID（免费版）
6. Bundle ID 会自动添加您的 Team ID 前缀
```

#### 3. 连接 iPhone
```
1. 用 USB 连接 iPhone 到 Mac
2. 在 iPhone 上点击"信任此电脑"
3. 打开"设置" → "通用" → "VPN与设备管理"
4. 信任您的开发者证书
```

#### 4. 运行应用
```
1. 在 Xcode 右上角选择您的 iPhone
2. 点击 Run ▶️
3. 等待编译和安装
4. 应用自动启动！
```

#### 5. 保持运行
```
注意：免费账号签名有效期 7 天
- 7 天内可以直接运行
- 超过 7 天需要重新签名
- 可以使用 Auto Code Sign 自动续签
```

## 🔧 快速启动脚本

创建 `快速启动.command` 文件：

```bash
#!/bin/bash

echo "======================================"
echo "  DeepSeek iOS 快速启动"
echo "======================================"
echo ""

# 检查 Xcode
if ! command -v xcodebuild &> /dev/null; then
    echo "[!] Xcode 未安装"
    echo "请访问 App Store 下载安装 Xcode"
    exit 1
fi

# 编译
echo "[1/3] 编译应用中..."
xcodebuild build \
  -scheme DeepSeek-iOS \
  -destination 'platform=iOS' \
  -configuration Debug \
  CODE_SIGNING_ALLOWED=YES \
  CODE_SIGN_IDENTITY="Apple Development"

if [ $? -ne 0 ]; then
    echo "[!] 编译失败"
    exit 1
fi

echo "[2/3] 编译成功！"
echo "[3/3] 请在 Xcode 中运行到 iPhone"
echo ""
echo "打开项目："
echo "open \"H:/桌面存储/deepseek harness/苹果手机端开发/DeepSeek-iOS.xcodeproj\""
echo ""
```

## 💡 常见问题

### Q: 没有 Mac 怎么办？
A: 使用云 Mac 服务：
- MacinCloud（约 $15/月）
- AWS EC2 Mac 实例
- 租用朋友的 Mac

### Q: 签名过期怎么办？
A: 
- 重新用 Xcode 运行一次（自动续签）
- 或使用 AltStore 自动续签

### Q: 应用闪退怎么办？
A: 检查：
- API Key 是否正确配置
- iOS 版本是否 >= 16.0
- 网络连接是否正常

### Q: 如何更新应用？
A: 修改代码后重新编译安装即可。

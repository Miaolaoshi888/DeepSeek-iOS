## 🔧 常见问题解决

### 问题 1：Xcode 提示"无法找到签名"
```
解决方案：
1. 打开 Xcode → Preferences → Accounts
2. 登录您的免费 Apple ID
3. 在项目中勾选"Automatically manage signing"
4. 选择您的个人账号
```

### 问题 2：安装后应用闪退
```
解决方案：
1. 检查 API Key 是否正确配置
2. 确认网络连接正常
3. 尝试重新编译运行
```

### 问题 3：签名 7 天后过期
```
解决方案：
- 重新用 Xcode 运行一次（自动续签）
- 或保持电脑开机，使用 AltStore 自动续签
```

### 问题 4：找不到 iPhone 设备
```
解决方案：
1. 确保 iPhone 已解锁
2. 检查 USB 连接是否正常
3. 在 iPhone 上点击"信任此电脑"
4. 重启 Xcode 再试
```

### 技巧 1：保持签名有效
```

2. 在 iPhone 上安装 AltStore
```

```bash
xcodebuild build \
  -scheme DeepSeek-iOS \
  -destination 'platform=iOS' \
  -configuration Debug
```

```bash

   ~/Desktop/DeepSeek-iOS.ipa
```

# DeepSeek AI 隐私政策

**最后更新日期：2026年1月9日**

## 引言

DeepSeek AI（以下简称"本应用"）尊重您的隐私。本隐私政策说明我们如何收集、使用、存储和保护您的信息。

## 1. 我们收集的信息

### 1.1 您主动提供的信息
- **API Key**：您提供的 Agnes AI API 密钥（存储在设备本地 Keychain 中）
- **对话内容**：您与 AI 的对话历史和消息
- **上传的文件**：您上传图片、PDF、文档等文件

### 1.2 自动收集的信息
- **设备信息**：设备型号、操作系统版本、应用版本
- **使用统计**：匿名使用数据（用于改进应用）
- **错误日志**：应用崩溃和错误信息（用于修复问题）

## 2. 信息的使用

我们使用收集的信息用于：
- 提供 AI 对话服务
- 保存您的对话历史
- 分析文件内容
- 改进应用功能和性能
- 修复技术问题

## 3. 信息的存储

### 3.1 本地存储
- **API Key**：使用 iOS Keychain 加密存储，永不离开您的设备
- **对话历史**：存储在设备本地 SQLite 数据库
- **上传的文件**：存储在设备本地，分析后删除

### 3.2 云端传输
- 对话内容通过 HTTPS 加密传输到 Agnes AI 服务器
- API Key 仅用于认证，不存储在我们的服务器
- 传输过程使用 TLS 1.3 加密协议

## 4. 数据的共享

**我们不会与任何第三方共享您的数据。**

- 对话内容仅在您和设备之间传输
- API Key 仅用于连接 Agnes AI 服务
- 不使用分析SDK或广告SDK

## 5. 您的权利

您有权：
- **查看**：查看您的对话历史和上传的文件
- **导出**：导出对话记录（文本或PDF格式）
- **删除**：删除所有对话记录和上传的文件
- **退出**：退出登录并清除 API Key
- **卸载**：卸载应用以清除所有本地数据

## 6. 数据安全

我们采取以下安全措施：
- 使用 iOS Keychain 安全存储敏感信息
- 所有网络传输使用 HTTPS + TLS 1.3
- 不在日志中记录敏感信息
- 定期进行安全审计

## 7. 儿童隐私

本应用不适合 13 岁以下儿童使用。我们不会 knowingly 收集儿童的个人信息。

## 8. 政策的变更

我们可能会更新本隐私政策。更新后，我们会在应用内通知您。重大变更我们会请求您的同意。

## 9. 联系我们

如您对本隐私政策有任何疑问，请通过以下方式联系我们：
- 邮箱：support@agents.com
- 网站：https://agents.com

## 10. 适用法律

本隐私政策受中华人民共和国法律管辖。

# 📦 Git 手动安装指南

> 由于网络问题，自动化安装失败。请按以下步骤手动安装。

---

## ⚡ 快速安装（2 分钟）

### 步骤 1：下载 Git
```
1. 打开浏览器
2. 访问：https://git-scm.com/download/win
3. 页面会自动检测您的系统
4. 点击蓝色的链接下载（约 50MB）
```

### 步骤 2：安装 Git
```
1. 找到下载的 file（通常在下载文件夹）
2. 双击 Git-xxx-64-bit.exe
3. 点击"运行"（如果弹出安全警告）
4. 所有选项使用默认设置，一路点击"Next"
5. 点击"Install"开始安装
6. 等待完成（约 1 分钟）
7. 点击"Finish"
```

### 步骤 3：验证安装
```
1. 关闭当前 PowerShell 窗口
2. 重新打开 PowerShell
3. 输入：git --version
4. 应该显示：git version 2.x.x
```

## 🆘 安装遇到问题？

### 问题 1：下载很慢
```
解决方案：使用国内镜像
访问：https://registry.npmmirror.com/mirrors/git/
选择最新版本下载
```

### 问题 2：安装失败
```
解决方案：
1. 右键点击下载的安装包
2. 选择"以管理员身份运行"
3. 重新安装
```

### 问题 3：找不到下载的 file
```
解决方案：
1. 打开下载文件夹
2. 搜索 "Git"
3. 找到最新的 .exe 文件
```

## 🔧 构建与发布

### 本地构建（Mac + Xcode）

```bash
# 清理
xcodebuild clean -scheme DeepSeek-iOS

# 构建模拟器版本
xcodebuild build \
  -scheme DeepSeek-iOS \
  -destination 'platform=iOS Simulator,name=iPhone 16 Pro Max' \
  -configuration Debug

# 构建真机版本
xcodebuild build \
  -scheme DeepSeek-iOS \
  -destination 'platform=iOS' \
  -configuration Release
```

## 🐛 故障排除

### Q: Xcode 无法打开项目？
A: 确保使用 Xcode 15.0+ 版本。旧版本可能不支持 Swift 5.9。

### Q: 编译错误 "Module not found"？
A: 运行 `swift package resolve` 或重新生成项目：
```bash
swift package generate-xcodeproj
```

### Q: API 连接失败？
A: 检查：
1. API Key 是否正确
2. 网络连接是否正常
3. 防火墙是否阻止请求

### Q: 真机调试失败？
A: 确保：
1. 开发者模式已开启（设置 → 隐私与安全性 → 开发者模式）
2. 设备已信任
3. 证书配置正确

### Q: 模拟器运行正常，真机崩溃？
A: 检查：
1. Info.plist 中的权限说明
2. 真机架构（arm64）
3. 最小部署目标版本
